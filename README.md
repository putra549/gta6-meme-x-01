# gta6-meme-x-01 — "Waiting for GTA 6 since 2013"

An entry for make.fun's ["Post a GTA 6 meme on X"](https://make.fun/bounty/gta6-meme-x-01) bounty.

The entry is an X post: a meme about the thirteen-year wait for GTA 6, with make.fun's ghost mascot in the picture
holding its magenta star coin next to a download bar stuck at 99%. `meme.png` is the picture and `caption.txt` is the
post's exact text; once the post is live, `POST.json` names its address and `main.ts` (Node 22, stdlib only) copies
`POST.json` to the output directory for the gate.
